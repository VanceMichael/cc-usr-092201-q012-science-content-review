# 科研成果科普审校

维护科研成果科普改写、专家审校和多载体发布资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括科学主张、来源证据、受众版本、审校意见、发布载体、观众反馈，状态示例为待改写 → 审校中 → 有分歧 → 已批准 → 已发布 → 需修订。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 活动把前沿科研成果转化为可看、可触和可玩的内容
- 展品覆盖空天、材料、制造和生命健康等领域
- 科普表达需要连接科研准确性与公众理解

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
