# 科研成果科普审校

维护科研成果科普改写、专家审校和多载体发布的**成果转化产品资料**：从科学主张与来源证据，到分龄分形态表达、专家确认、分歧留痕、版本化载体与观众反馈回流，形成可逐句追溯证据的闭环。

## 解决的问题

- 科研人员担心通俗改写失真，教育团队认为原稿超出儿童认知，来回传文档无法确认哪句话仍有证据；
- 研究更新、数字修正、敏感细节删减、多人意见冲突需要可追溯，而不是覆盖旧稿；
- 已印刷载体不能被新版悄悄替换，讲解员在现场需要拿到"当前版本"；
- 观众的疑问与误解要回流到**具体表达版本**，内容团队只修正受影响部分。

## 资料范围

| 文件 | 作用 |
| --- | --- |
| `fixtures/domain.json` | 完整样例资料（虚构标识，不含真实个人资料或凭据），schema 版本 v2 |
| `contracts/domain.schema.json` | 数据契约，规定各记录类型的字段与取值 |
| `src/domain.js` | 解析、规则校验（错误/提醒）与业务查询 |
| `test/domain.test.js` | 18 项规则测试，`npm test` 运行 |

## 记录模型

```
课题 topics
 └─ 科学主张 claims（版本化：陈述 + 数字 + 适用范围/不主张事项 + 变更原因）
     ├─ 来源证据 evidence（公开/受限；声明支持哪些主张版本）
     └─ 受众版本 expressions（展签/互动脚本/翻译/无障碍文本/安全提示 × 年龄段）
          · 每个表达版本绑定一个主张版本 based_on_claim_version
          · confirmed_by：对应课题科研专家按"主张版本×表达版本"确认
分歧 disputes（双方原话永久保留，裁定产出新表达版本）
变更事件 change_events（研究更新/数字修正/敏感细节删减/意见冲突）
载体 carriers（印刷展签=固定版本 pins；互动屏/讲解平板=live_bindings）
二维码 qr_codes（讲解员/观众现场入口）
观众反馈 feedback（about 精确定位到 expression 版本）
```

样例含两个课题：**强流重离子加速器**（设计/调试数字修正、辐射安全与敏感细节删减）与**微重力液体运输**（3.2→2.7 秒研究更新、7-10 岁比喻引发的专家—教育团队分歧）。

## 核心规则（由 `validateDomain` 强制）

1. **逐句有据**：表达版本只能引用支持其依据主张版本的证据，否则 `E_EVIDENCE_SCOPE`。
2. **专家确认**：`已发布` 表达必须有**对应课题**科研专家针对该主张版本与表达版本的确认（越权专家无效），否则 `E_PUBLISHED_UNCONFIRMED`。
3. **适用范围随行**：每个主张版本携带 `scope / conditions / not_claimed`，数字带测量时点与不确定度。
4. **受限隔离**：受限证据进入在展公众表达即阻断 `E_RESTRICTED_EVIDENCE_PUBLIC`；仅在未发布草稿中出现时给提醒。
5. **分歧留痕**：分歧必须保留双方立场原话；裁定只允许产出新版本，旧版本标 `已被取代/已撤回` 不删除。
6. **印刷不可变**：印刷载体 `immutable_after_print`，只能增发新批次（如 B-2026-03 → B-2026-06），不允许实时绑定、不覆盖旧批次 pin。
7. **精准修订**：变更事件经 `affectedExpressions` 只圈出该主张下受影响表达，区分已重写 `remediated` 与仍 `需修订` 的 `stale`（如数字修正后英文翻译只需更新数字从句）。

## 现场与机构视角

- 讲解员扫码 `resolveQr(code)`：
  - 印刷批次 → 返回固定原文（`pinned_body`）与当前批准版本（`current_body`）对照及口播提示，旧板不回收；
  - 互动屏/平板 → 返回各绑定表达的当前版本与待修订标记。
- 研究机构 `institutionReport()`：按专家查看自己的确认、所参与分歧的裁定结果与留档状态、触发的变更事件，以及每条观众反馈的处理去向。
- 反馈溯源 `traceFeedback(id)`：观众疑问 → 具体表达版本 → 主张版本、适用范围、证据与确认记录；误解可路由为分歧并链接到修订后的新版本。
